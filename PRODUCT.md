# Product

<!-- impeccable:product-schema 1 -->

## Platform

Windows native desktop, Rust/egui.

## Users and purpose

Minecraft players diagnosing failed launches and added-mod conflicts, especially in Prism, Lunar and Dawn profiles. The user wants fast access to help through profile selection, file import or pasted console output, with specific version guidance and minimal interface clutter.

## Constraints

Offline diagnosis and manual import work without an account or key. Original profiles remain read-only. Every cloud request requires reviewed redacted evidence and consent. Public mod metadata lookup is opt-in; verified mod downloads require separate consent in a reviewed repair-copy plan. Published release compatibility labels do not establish runtime compatibility.

## Brand commitments

Keep the Minecraft Ai Doctor name and use the supplied vector source at assets/logo.svg. Its Figma angular-gradient metadata is converted to portable SVG at build/render time; the original source stays unchanged. The older PNG is retained as a documentation fallback/test asset. The ring is the app identity. Preserve the native desktop runtime and existing analysis capabilities.

## Success

Users can identify the affected mod, installed version, required range and matching published release when verifiable, understand what remains uncertain, and copy a clear fix checklist. Launcher profiles are visibly separated. No version or fix is fabricated to fill a gap.
