# Privacy and consent

Minecraft Ai Doctor starts offline and makes no automatic network requests. Discovery enumerates known launcher profile directories and an optional custom root, reading small profile manifests, Prism instance names/icon keys and named local artwork. It does not inspect account databases. Analysis reads selected logs, top-level mod JAR descriptors and Prism component-version metadata. It does not read Minecraft account files, cookies, browser data, worlds or authentication caches, or modify launcher instances.

Imported text is retained in application memory, including up to four session-cached reports, until evicted or the app exits. No full-log telemetry or automatic raw-log report file is written. Redacted validated AI responses are cached locally for 7 days, and public Modrinth metadata for 6 hours, under `%LOCALAPPDATA%\PrismAIDoctor\cache-v1`. API keys and request payloads are not cached. These caches are bounded and can be cleared in Settings. Redaction is best effort, including for saved AI prose. Reports are written only to a user-selected export destination. CLI reports go to standard output. OS-level swap, crash dumps or the user's own terminal recording are outside these guarantees.

Cloud analysis is an explicit action: prepare payload → inspect complete JSON → check consent → Send. The app sends selected redacted evidence, local finding titles and a bounded mod ID/version list with an instruction prompt. Paths in the payload are redacted. Google requests go to `generativelanguage.googleapis.com`; Groq requests go to `api.groq.com`. Each requires your own API key. Provider terms, billing and data retention apply. HTTPS still exposes network metadata such as your source IP to the provider.

Redaction covers common home paths/usernames, token/session/key assignments, known key formats, authorization values, UUIDs, email addresses, IPv4/IPv6 and URLs. It cannot identify every possible private value, unusual nickname, custom path, chat message or secret. Always review previews and exports before transmission. Authentication headers are deliberately excluded from the preview; they carry only the selected provider's API key. Retrying a transient provider failure may repeat the same consented payload up to three attempts.

Keys entered in Settings are masked and stored under the legacy service `Prism AI Doctor` (preserved after the rename to keep saved keys accessible) in Windows Credential Manager. Only this app's `GEMINI_API_KEY` / `GROQ_API_KEY` entries are queried. The environment is a fallback. Keys are never written to application configuration or diagnostic logs. Keys and imported data live in process memory; this version does not promise memory zeroization. Removing a stored key does not remove an environment variable.

Cloud cancellation aborts the active HTTP future and bounded retries. A payload already received by a provider cannot be recalled. Every subsequent Send requires new consent. There is no persistent blanket consent switch.

The **Find a replacement** panel contacts `api.modrinth.com` only after a user action and uses cached metadata when available. It sends the displayed mod query and any known game/loader filters; choosing a project sends its public project ID plus release filters. Confirming **Use this project** also loads its public icon from direct HTTPS `cdn.modrinth.com` URLs, with no redirects. Icons are bounded to 512 KiB, decoded with pixel/allocation limits, and cached for 7 days. A saved project/icon association allows later imports to reuse cached artwork without another request. Clearing saved API results also clears cached artwork. No log text, local paths or API keys go to Modrinth. Requests use a distinct User-Agent, HTTPS, bounded responses, timeouts, cancellation and transient retries. Opening a release link hands the public page to your browser.

**Auto-fix** requires review and an Apply action. It writes only a new mod-only repair copy in the app workspace, leaving the original instance read-only. The journal records changed filenames and hashes; backups retain original copied JARs for rollback. Worlds, accounts and personal configuration are excluded. These copies persist until you remove them; clearing API results does not remove backups. Replacement downloads require a separate explicit checkbox and Download & apply action. Only the reviewed public file is requested from `cdn.modrinth.com`, with no API key or log data, and its size/SHA-512 and mod descriptor must verify. Temporary staging is removed on normal success/failure; an abrupt process exit can leave staging files. No mod or model-generated code is executed.

**Paste console** reads only the text you explicitly paste into its editor. It does not poll the clipboard, save a temporary log or inspect other applications. Pasted text shares the same redaction/preview/consent requirements as file imports. Close or clear the input when you no longer need it.

Evidence/model output is untrusted data. No model-generated commands are executed and no tools are exposed to the model. The model may select allowed finding indexes for a repair proposal; local code independently constructs the supported file operations, and the user must review and apply them. Schema/citation checks do not prove the truth of free-form AI prose. Structured claims are validated; explanations remain labelled unverified.

Exports are redacted and use create-new semantics. The app rejects common launcher folder destinations. You remain responsible for choosing a location outside portable/custom game folders and reviewing the exported content. Source opening passes an existing log path as a separate Notepad argument; JARs are never opened as executables.
