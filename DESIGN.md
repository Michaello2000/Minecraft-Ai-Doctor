# Desktop interface

Operate mode: a quiet diagnostic workspace. The user selected a dark interface. Modernize spacing and type, and use the chroma ring as the sole prominent brand asset.

Use a neutral charcoal background, a slightly raised content surface, light readable text, muted secondary text, and a restrained cool-violet action color. Red/amber communicate errors/warnings only. Selected rows use a readable foreground on a tinted surface; color is accompanied by text.

Navigation is compact. Profiles use launcher tabs, search and aligned rows. Analysis starts with File / Paste console choices and presents a summary, compact issue selection, version facts, a fix checklist and optional details. Network data and uncertain recommendations are explicitly labelled. Advanced lab and provider configuration remain available but do not dominate the main workflow.

The replacement panel uses two explicit steps: confirm the mod project, then choose the exact Minecraft version and loader. Missing game versions are visible editable fields. An arrow appears only for an actual version change. Mod icons come from local JARs or a user-confirmed public project; instance rows reuse exposed local launcher artwork and otherwise show an initials/version tile.

Crowded reports group duplicates, version conflicts, missing dependencies, runtime errors and unconfirmed observations. Concrete duplicate fixes come first. The affected-mod list scrolls independently; one selected finding stays in focus. Local JAR artwork identifies mods, with labelled fallbacks. Current → proposed states use a drawn arrow. Auto-fix starts from a top toolbar action and reveals a bounded review panel; it always targets a separate mod-only copy with recoverable backups.

Use 8/12/16/24/32 point spacing, 14–15 point body text, 20–28 point headings, 34 point primary headings, consistent 8 point control corners, and a readable prose width. All repeated controls have stable unique IDs. Narrow windows stack content instead of squeezing fields. No decorative animation, gradients, nested card grids or repeated privacy slogans.
